# Плейбук «Продающий рилс от обратного»
### Как ставить детальное ТЗ генератору коротких видео, чтобы на выходе был продающий рилс по стандартам

> Пайплайн проекта: сценарий → HeyGen API (аватар/озвучка) → ffmpeg (субтитры, SFX, CTA-кадр).
> Рабочая ниша-пример: **«Шаманские обряды и ритуалы для Рода»**.
>
> ⚠️ Фото с концепциями не дошли до исполнителя. Ниже — полный стандартный набор из 12 концепций продающих рилс + 3 дополнительные. Когда пришлёте список/фото — мапим ваши названия на этот плейбук и дописываем недостающее.

---

## 0. Главная идея «от обратного»

Продающий рилс **не сочиняют от хука** — его **проектируют от продажи**.

```
ПРОЕКТИРУЕМ:   CTA → ОФФЕР → ВОЗРАЖЕНИЕ → ОБЕЩАНИЕ → ДОКАЗАТЕЛЬСТВО → БОЛЬ → ХУК
ПУБЛИКУЕМ:     ХУК → БОЛЬ → ДОКАЗАТЕЛЬСТВО → ОБЕЩАНИЕ → ОФФЕР → CTA
```

Хук, который не приводит к CTA, — это кликбейт. CTA, к которому не ведёт хук, — приклеенная фраза. «От обратного» гарантирует, что цепочка неразрывна.

---

## 1. Стандарты продающего рилса (контрольная рамка)

| Параметр | Стандарт |
|---|---|
| Длительность | 20–40 сек продающий; списки/чек-листы до 60 сек (нумерация удерживает) |
| Хук | 1–3 сек. Без «привет/меня зовут». Первый кадр = обложка с тезой-хуком |
| Единство | Один ролик = одна мысль = один CTA |
| Смысловой блок | 3–7 сек, дальше поворот/новый аргумент |
| Паттерн-интеррапт | Каждые 2–4 сек: зум, джамп-кат, смена плана, SFX-акцент |
| Субтитры | Дублируют речь, строки по 3–5 слов, крупно, в сейф-зонах (низ ~250px, верх ~200px) |
| Звук | Голос в приоритете, музыка −20…−25 дБ под голосом, 2–4 SFX-акцента |
| CTA | Последние 3–5 сек + статичный кадр 1–2 сек. ≤6 слов: глагол + кодовое слово + куда |
| Закадр (30 сек) | ~60–75 слов текста для озвучки |
| Ориентиры удержания | 3-я сек ≥ 70% · середина ≥ 45–50% · досмотр ≥ 25–30% |
| Диагностика провалов | Провал на 1–3 сек → переписать хук; на середине → резать воду; перед CTA → CTA поздний/внезапный |

**Тест обратной сборки (перед генерацией и перед публикацией):** читаем цепочку вслух вперёд — каждый блок отвечает на вопрос, который задал предыдущий; удаление любого блока ломает продажу; CTA — единственный логичный следующий шаг.

---

## 2. Мастер-алгоритм «от обратного» — 7 шагов + шаг 0

**Шаг 0. Единственное целевое действие.** Что зритель должен СДЕЛАТЬ после просмотра? Один вариант: написать кодовое слово в директ / перейти по ссылке в шапке / записаться на диагностику / сохранить и отправить подруге. Не два. Не три.

**Шаг 1. CTA-фраза.** Глагол + кодовое слово + место: «Напиши “РОД” в директ». Всё, что не ведёт к ней — вычеркнуть.

**Шаг 2. Оффер.** Что человек получит: формат + выгода + снижение риска. Пример: «Диагностика рода 40 минут: выявим повторяющийся сценарий, план из 3 шагов, без “страшилок” и давления».

**Шаг 3. Возражение-фильтр.** Главное «а что, если…» аудитории — и одна фраза-антидот внутри ролика. Для эзо-ниши топ-возражения: «это шарлатанство» → показать механику/системность; «страшно трогать род» → «диагностика — это взгляд, а не вмешательство»; «не по вере» → «работаем с семейной историей, а не с религией».

**Шаг 4. Обещание (ключевая выгода).** Обратная сторона боли, конкретно. Не «гармонизация энергий», а «перестать повторять сценарий разводов по женской линии».

**Шаг 5. Доказательство.** Одно: кейс / демонстрация процесса / цифра практики / логика механизма («род передаёт не только гены, но и сценарии — вот пример»).

**Шаг 6. Боль/триггер.** Словами клиента (из директа и комментариев), а не словами эксперта. «Я как будто проживаю мамину жизнь» — боль. «Негативные родовые программы» — экспортный жаргон, доверия не даёт.

**Шаг 7. Хук.** Стоп-фраза на 1–3 сек, три проверки: (а) цепляет именно ЦА, (б) честна — ролик реально отвечает на интригу, (в) на неё нельзя мысленно ответить «ну и ладно», не досмотрев.

## 3. Универсальный шаблон ТЗ генератору

```text
РОЛЬ
Ты — сценарист продающих коротких видео (Reels/Shorts) в нише {НИША}.
Пишешь по стандартам удержания: хук 1–3 сек, смысловой блок 3–7 сек,
паттерн-интеррапт каждые 2–4 сек, один ролик = одна мысль = один CTA.

ВХОДНЫЕ ДАННЫЕ
Продукт: {что продаём: формат, длительность, цена, что входит}
ЦА: {кто: возраст, пол, боль словами клиента, желание, топ-3 возражения, холодная/тёплая}
Цель ролика: {единственное действие: кодовое слово в директ / ссылка в шапке / запись}
Концепция: {К1–К12 из списка} 
Длительность: {20 / 30 / 40 / 60 сек}
Тон: {спокойный эксперт / тёплый рассказчик / жёсткая провокация}
Запреты: без медицинских и финансовых гарантий, без запугивания, без жаргона ЦА.

ЗАДАЧА — собери ролик «от обратного»:
1. Сформулируй CTA (глагол + кодовое слово + куда, ≤6 слов).
2. Запиши оффер: формат + одна ключевая выгода + снятие риска.
3. Назови главное возражение и одну фразу-антидот внутри ролика.
4. Сформулируй обещание — конкретную выгоду, зеркало боли.
5. Выбери ОДНО доказательство: кейс / процесс / цифра / механизм.
6. Запиши боль словами клиента.
7. Напиши 3 варианта хука на 1–3 сек; каждый должен логически «требовать»
   цепочку боль → доказательство → оффер → CTA.
8. Собери ролик вперёд. Проверка: каждая секунда продаёт следующую;
   удаление любого блока ломает продажу; CTA — естественный финал, не наклейка.

ФОРМАТ ОТВЕТА (под пайплайн HeyGen + ffmpeg):
Таблица: № | таймкод | закадровый текст (для озвучки) | текст на экране (субтитры/тезы)
        | визуал/план | SFX / паттерн-интеррапт | visual prompt (EN, если генерим футаж)
Отдельно: а) 3 варианта хука; б) текст CTA-кадра (статичный, 1–2 сек);
в) закадровый текст сплошняком (все слова, ≤{N} слов под {сек} сек);
г) описание поста 150–300 знаков + вопрос для комментариев; д) 5 хэштегов.
```

## 4. Концепции: алгоритм «от обратного» + каркас + пример в нише

> Обозначение каркаса: секунды ориентировочны — масштабируйте под длительность, сохраняя пропорции.

---

### К1. PAS: Проблема → Усиление (Agitate) → Решение

**Когда:** боль явная, ЦА её осознаёт. Рабочая лошадка продающих рилс.

**Алгоритм от обратного:**
1. CTA → 2. Решение = продукт (что это, как проходит, снятие риска) → 3. Три «качания» боли по нарастающей: *сейчас → если не решать → кого ещё заденет* → 4. Формулировка проблемы словами клиента → 5. Хук-диагноз: фраза, от которой ЦА узнаёт себя.

**Каркас (30 сек):** 0–3 хук → 3–9 проблема → 9–18 три качания с текстом на экране → 18–26 решение + как проходит → 26–30 CTA.

**Пример (Род):**
- Хук: «Три развода по женской линии — это не “не везёт”. Это сценарий рода.»
- Проблема: «Раз за разом отношения ломаются об одно и то же.»
- Качания: «Сначала думаешь — совпадение. Потом видишь у дочери те же ссоры. Потом понимаешь: ты проживаешь не свою жизнь.»
- Решение: «На диагностике рода находим, где сценарий запустился, и обрядом возвращаем ему хозяйку — эпоху, в которой он родился.»
- CTA: «Напиши “СЦЕНАРИЙ” в директ — разберу вашу линию.»

---

### К2. AIDA: Внимание → Интерес → Желание → Действие

**Когда:** охватный ролик на холодную ЦА; нужно создать спрос с нуля за 30–40 сек.

**Алгоритм от обратного:**
1. CTA с ограничителем («первым 5», «до пятницы») → 2. Три выгоды «жизни после» (желание) → 3. Доказательство → 4. Интерес = новизна механизма («как это работает») → 5. Хук-внимание: конкретная, чуть провокационная постановка проблемы.

**Каркас (35 сек):** 0–3 внимание → 3–10 интерес (механизм) → 10–25 желание (3 выгоды, нумерация на экране) → 25–31 доказательство → 31–35 действие.

**Пример (Род):**
- Хук: «Почему в одних семьях деньги копятся, а в других “сгорают” за день?»
- Интерес: «У рода есть денежный потолок: бабушке было опасно богатеть — внучке “не даёт” подсознание.»
- Желание: «Что меняется после проработки: 1) перестаёшь сливать неожиданные суммы; 2) спокойно берёшь дорогие заказы; 3) детям передаёшь подушку, а не страх.»
- Доказательство: цифра практики / 1 кейс.
- CTA: «Напиши “ДЕНЬГИ” — первым 5 разбор потолка бесплатно.»

---

### К3. «До → После → Мост» (BAB)

**Когда:** есть контраст результата, который легко почувствовать; тёплая ЦА.

**Алгоритм от обратного:**
1. CTA → 2. Мост: конкретное действие-продукт, соединяющий состояния («что именно сделано») → 3. «После» в ощущениях (не «стало хорошо», а «просыпаюсь без камня в груди») → 4. «До», максимально узнаваемое → 5. Хук-контраст: спайка «до/после» в первой фразе.

**Каркас (25 сек):** 0–3 хук-контраст → 3–10 до → 10–17 после → 17–22 мост → 22–25 CTA.

**Пример (Род):**
- Хук: «Раньше звонок мамы вызывал у неё дрожь. Теперь они ездят друг к другу в гости.»
- До/после по 2–3 конкретным маркерам (снов, тела, быта — не абстракций).
- Мост: «Одна диагностика рода + ритуал завершения старой обиды.»

---

### К4. Сторителлинг-кейс (история клиента / личная)

**Когда:** нужно доверие; продаём дорогое; аудитория любит «послушать истории».

**Алгоритм от обратного:**
1. CTA → 2. Мораль: вывод, который делает оффер логичным («проблема была не в ней, а в сценарии по женской линии») → 3. Результат героя (то, чего хочет ЦА) → 4. Поворот: какое действие к нему привело → 5. Драма: дно, узнаваемое ЦА → 6. Герой: портретом совпадает со зрителем (возраст, статус, боль) → 7. Хук: фраза из пика драмы или из результатa — с недосказанностью.

**Каркас (40 сек):** 0–3 хук-пик → 3–10 герой и драма → 10–18 попытки и тупик → 18–28 поворот (что нашли на диагностике) → 28–34 результат → 34–40 мораль + CTA.

**Пример (Род):**
- Хук: «Она 12 лет не разговаривала с мамой. Причина нашлась в 1943 годе.»
- Драма → тупики («психологи, тренинги — откаты») → поворот («по женской линии три поколения гневали матерей — нашли точку») → результат → мораль: «не всякая обида ваша. Некоторые — наследство, и их можно вернуть.»

---

### К5. Разрушение мифа: Миф → Правда → Что делать

**Когда:** в нише много страхов/стереотипов (для шаманики — хлеб). Бонус: спор в комментариях разгоняет охват.

**Алгоритм от обратного:**
1. CTA → 2. Правильный шаг (что делать вместо) → 3. Правда с 2 аргументами → 4. Миф — точной цитатой ЦА (в неё должна верить половина зала) → 5. Хук = миф + вопрос: «“Чистка рода опасна”? Отвечаю как практик с 12 годами».

**Каркас (30 сек):** 0–4 миф-хук → 4–14 почему миф неверен (2 аргумента) → 14–22 как на самом деле → 22–27 микро-доказательство → 27–30 CTA.

**Примеры мифов ниши:** «родовая работа — это про религию» / «если не трогать — само рассосётся» / «это страшные ритуалы с жертвоприношениями» (показать цивильную диагностику — сильный паттерн-интеррапт).

---

### К6. Список ошибок: «N ошибок, которые…»

**Когда:** ЦА сама «болтается» в теме и боится навредить. Нумерация удерживает до конца.

**Алгоритм от обратного:**
1. CTA («полный чек-лист — по кодовому слову») → 2. Антидот к каждой ошибке (по фразе) → 3. Ошибки отсортировать: №1 — самая частая (узнавание), последняя — самая дорогая (страх потери ведёт к CTA) → 4. Хук-угроза ошибкой: «3 ошибки, которые усиливают то, что вы пытаетесь убрать».

**Каркас (40 сек):** 0–3 хук → 3–30 ошибки по 7–9 сек (ошибка → последствие → антидот) → 30–37 связка с оффером → 37–40 CTA.

**Пример (Род):** ошибки — 1) молчать о «вычеркнутых» из семьи (молчание = передача дальше); 2) поминать с укором, а не с благодарностью; 3) пугать детей «нашей семейной историей». Антидоты → «порядок даю на диагностике».

---

### К7. ТОП-признаки / чек-лист: «N признаков, что…»

**Когда:** холодная ЦА, которую нужно «диагностировать» через просмотр. Самосегментация: зритель сам понимает, что ему надо.

**Алгоритм от обратного:**
1. CTA («если 2+ признака про вас — кодовое слово») → 2. Развязка: «это не приговор, вот первый шаг» → 3. Признаки: №1 — самый массовый, финальный — самый тревожный (доводит до CTA) → 4. Хук-дозировка: «5 признаков, что ваш род просит внимания. Третий — почти у всех.»

**Каркас (45–60 сек):** 0–3 хук → 3–40 признаки по 6–7 сек с нумерацией → 40–52 развязка → 52–60 CTA.

**Пример (Род):** повторяющиеся болезни по линии; несчастья у носителей одного имени; деньги не задерживаются; сны с умершими; «детские» страхи в 35+.

**Правило:** признак = симптом словами клиента, без диагностики в лоб.

---

### К8. Секрет / инсайд: «То, что вижу только практик»

**Когда:** продаём диагностику/разбор — продукт-вход. Инсайд продаёт саму услугу, в которой инсайдов больше.

**Алгоритм от обратного:**
1. CTA («полная диагностика — глубже в 10 раз») → 2. Граница: «всё дерево показываю на сессии» → 3. Три инсайда (поднимаем занавес на 10%) → 4. Обещание « покажу, как читается род» → 5. Хук: «Что я вижу в вашем родовом древе за первые 3 минуты диагностики».

**Каркас (30 сек):** 0–3 хук → 3–20 три инсайда → 20–26 граница «а дальше — на диагностике» → 26–30 CTA.

**Принцип:** бесплатный инсайд должен быть ценным, но создавать аппетит, а не насыщать.

---

### К9. Провокация / «от противного» / антитренд

**Когда:** ниша перегрета низким чеком и «халявщиками»; нужно отсеять и продать зрелому клиенту дороже.

**Алгоритм от обратного:**
1. CTA → 2. Кому НАДО (портрет зрелого клиента) → 3. Кому НЕ надо (список отсева) → 4. Тезис-переворот → 5. Хук-разворот: «Не приходите на чистку рода, если…»

**Каркас (25 сек):** 0–3 хук-отказ → 3–15 «если ждёте волшебную таблетку / обвиняете предков вместо жизни» — отсев → 15–21 «а если готовы встретиться со своей историей честно...» → 21–25 CTA.

**Пример:** «Хватит называть лень “родовым проклятием”. Проклятий у 90% из вас нет — есть непрожитые истории. Это хорошая новость: с историей можно работать.»

**Риск-менеджмент:** провокация по боли, не по уязвимости (не бить по traмве, вере, политике).

---

### К10. Процесс / бэкстейдж (эстетика ритуала)

**Когда:** продукт атмосферный, визуальный. Продажа через ощущение + ASMR-удержание.

**Алгоритм от обратного:**
1. CTA («хочешь свою — кодовое слово») → 2. Интрига скрытого: «полный ритуал — только на сессии» → 3. Показ 3 элементов с объяснением смысла каждого → 4. Обещание атмосферы → 5. Хук: «Сбор обряда на очищение рода: каждый предмет здесь — не декорация».

**Каркас (30 сек):** 0–3 хук + крупный план → 3–24 три элемента: показ (2–3 сек макро) → смысл (1 фраза) → 24–27 интрига → 27–30 CTA.

**Монтаж:** макропланы фактур (травы, свеча, песок, перо, бубен), звуки фактур в микс, голос поверх.

---

### К11. Социальное доказательство: отзыв / кейс / цифры

**Когда:** аудитория интересуется, но не решается. Дожим.

**Алгоритм от обратного:**
1. CTA («вы следующая история») → 2. Механика «как такое повторить» → 3. Кейс с деталями: кто, что было, что стало (без пафоса) → 4. Зачем показываю: «спрашиваете — работает ли» → 5. Хук-агрегат: «400 семей прошли диагностику. Вот что повторяется у 8 из 10».

**Каркас (30 сек):** 0–3 хук-цифра → 3–20 кейс/скрин отзыва (с согласия) → 20–26 «как повторить» → 26–30 CTA.

**Правило:** конкретика > восторги. «Наладились отношения со свекровью за месяц» продаёт лучше, чем «изменилась жизнь!!!»
**Легально:** согласие на публикацию, без обещаний «у вас будет так же».

### К12. FAQ / «вопрос из директа»

**Когда:** контент-конвейер: один вопрос = один рилс. Собирает вовлечённую ЦА и закрывает возражения сериями.

**Алгоритм от обратного:**
1. CTA («остались вопросы — директ / запись») → 2. «Как правильно» в 2–3 пунктах → 3. Развёрнутое «почему» → 4. Короткий ответ сразу (да/нет в первые 5 сек — честность удерживает) → 5. Хук = цитата вопроса дословно.

**Каркас (25 сек):** 0–3 вопрос-цитата на экране → 3–6 короткий ответ → 6–18 почему → 18–22 как правильно → 22–25 CTA.

**Пример (Род):** «Можно ли работать с родом без ведома родственников?» → «Можно. Вы работаете со своим местом в системе, а не “за” кого-то» → почему → как → CTA «“РОД” в директ».

## 5. Дополнительные концепции (если были на фото)

- **Сравнение X vs Y:** «Психотерапия или работа с родом — что когда». От обратного: CTA ← «чего не решает X» ← честная симметрия (Y не «враг» — доверие) ← хук-дилемма: «3 года у психолога, а сценарий повторяется. Почему?»
- **POV / тренд-переупаковка:** берём трендовый формат/звук → подменяем смысл на нишу. От обратного: CTA ← нишевой смысл ← трендовая механика ← хук «как у всех, но...».
- **Прямой оффер:** только для прогретой аудитории. От обратного: дедлайн ← состав мест/цена ← кому ← хук-объявление: «Открыла 5 мест на обряд очищения рода до конца месяца».

## 6. QC-чек-лист перед рендером и публикацией

- [ ] Одно целевое действие? Хук сходится с CTA одной логической линией?
- [ ] Хук 1–3 сек, без приветствий; на нём нельзя «закрыть вопрос» в уме?
- [ ] Боль — словами клиента, а не эксперта?
- [ ] Одно доказательство, конкретное (цифра/кейс/процесс/механизм)?
- [ ] Главное возражение закрыто одной фразой?
- [ ] Обещание конкретное, без медицинских/финансовых гарантий?
- [ ] Каждые 2–4 сек паттерн-интеррапт (помечены в таблице SFX/планов)?
- [ ] Закадр ≤ 75 слов на 30 сек; субтитры 3–5 слов в строке, сейф-зоны?
- [ ] CTA ≤ 6 слов: глагол + кодовое слово + куда; статичный CTA-кадр 1–2 сек?
- [ ] Прямая читка цепочки вслух — нет «дыр» и воды?
- [ ] Есть 3 варианта хука для A/B?
- [ ] Описание поста задаёт вопрос для комментариев?

## 7. Итерации: как читать аналитику и переписывать

1. **3 хука на одну середину.** Генерируем 3 версии ролика, отличающихся только первым блоком (0–3 сек + обложка). Победитель по удержанию 3-й сек → масштаб.
2. **Читаем график удержания точечно:**
   - обвал 0–3 сек → хук/обложка;
   - ступень в середине → блок с «водой» — резать или менять аргумент;
   - обвал перед CTA → CTA выпадает из сюжета: добавить «мостик» («чтобы получить чек-лист — …»).
3. **Комментарии = новые боли** → новая концепция К12/К6.
4. **Серийность:** одна боль → 3–4 ролика на разных концепциях (К1, К5, К7, К12). Разные входы в один оффер.
5. **Метрики продажи:** доля досмотревших, кликнувших CTA; директ-конверсия по кодовому слову (а не только охваты).
