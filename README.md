# REELS-RENDERER 2026: Автоматизированный Завод Продающего Контента и ИИ-Воронок

Платформа проектирования, рендеринга и автоматизации продающих коротких видео (Reels / Shorts) с нейро-интеграцией HeyGen API, ffmpeg и сквозной продуктовой линейки.

---

## 🚀 Обзор Системы 2026

Архитектура проекта включает полную цепочку нейро-продаж «от обратного» для экспертов и предпринимателей:

1. **100 Продающих Сценариев Reels / Shorts:**
   - 10 тематических блоков по 10 сценариев, привязанных к конкретным Лид-магнитам.
   - Стандарт кадра: 9-кадровая сетка (Storyboard Grid) с точным таймингом A-roll / B-roll / CTA.
   - Продающие стратегии: **PAS, AIDA, BAB, Storytelling, Разрушение мифов, Чек-листы, Секреты/Инсайды, Провокации, ASMR/Процессы, Соцдоказательства, FAQ**.

2. **10 Сквозных Цепочек Продаж (Воронок Смыслов):**
   - **Лид-магнит (0 ₽)** — Мгновенное вовлечение в DM / Telegram (кодовые слова `1`–`10`).
   - **Микро-продукт (до 1 000 ₽)** — Окупаемость трафика в первый же день (промпт-паки, JSON-шаблоны).
   - **Мини-продукт (до 5 000 ₽)** — Глубокий практикум, воркшоп или интенсив по инструментам.
   - **Стандартный продукт: Клуб «Царство» (12 000 ₽/мес)** — Закрытое рекуррентное сообщество.
   - **Флагманский продукт: Наставничество «Траектория» (от 180 000 ₽/квартал)** — Индивидуальная архитектура бизнеса и внедрение ИИ-агентов под ключ.

## 🛠️ Запуск Генераторов и Компиляция PDF

Для регенерации документов и PDF-файлов выполните команды в терминале:

```bash
# 1. Генерация базы 100 сценариев Reels
python3 scripts/generate_100_reels.py

# 2. Генерация векторной SVG-схемы
python3 scripts/generate_svg_diagram.py

# 3. Компиляция всех PDF-документов в темном дизайнерском стиле
python3 scripts/generate_all_pdfs.py
```
